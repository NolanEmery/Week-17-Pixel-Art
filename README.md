# Week-17-Pixel-Art
Plan It:

What is the goal of the website?

Make an app for placing blocks. The goal is to create 3d art using these blocks (voxels).

Who are you building for, and what do they care about?

The audience is artists who want to design 3D art on a computer.

Describe how a user should use the voxel editor from the moment they visit the site. What should they see first, what should they click, and what should happen next?

Include a grid in the middle where the user can place their voxels. Put the options for different layers on the side. Allow the user to use either orbit or free-cam to view their work. 

How should the voxel editor work? (3D view, placing voxels, colors, delete, save/load)

Placing blocks on top of other blocks takes the user up a level. Make their work saveable and shareable. Have a feature for grouping the blocks that allows the user to change the features of all blocks in the group. When the user places a new block, that block takes all the features of the previous block. Allow the user to select the color of their blocks.

What words best describe the look and feel that you want?

Organized, easy to use. Have a gray background and a white grid for where the user places their blocks.

Test It:

Make the voxels 3D and allow voxels to be placed one on top of another. Add the ability to delete voxels.

Expand It:

Have text to guide the user through all the tools. Have a starter voxel in the middle of the grid.
